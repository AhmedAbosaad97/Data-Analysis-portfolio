# Excel project

**☕ Coffee Chain Sales Analysis – Uncovering Key Retail Trends**

I recently analyzed a coffee chain’s retail sales dataset using MS Excel to extract actionable insights. Here’s a breakdown of my process and findings:

🔍 Objectives

- Calculate total sales & transactions
- Identify top-performing stores & products
- Analyze sales trends by time and month

🛠️ Skills & Tools Used

- Power Query (Data cleaning & transformation)
- Pivot Tables & Charts (Data summarization & visualization)
- Dashboard Creation (Interactive reporting)

📊 Key Insights

✅ Total Sales: $698,812.33 (149,116 transactions)

✅ Top Store: Hell’s Kitchen ($236,511.17 in sales)

✅ Peak Sales Month: June (Highest revenue)

✅ Sales Trend:
Steady growth over time, with a dip in February.
Peak Sales Hours: 8:00 AM – 10:00 AM (Morning rush!)

✅ Top 3 Products: Coffee, Tea, Bakery in order

🔧 My Process

1️⃣ Data Cleaning (Power Query)
Checked for duplicates & misspellings → None found
Corrected data types (dates, times)
Added a "Sales" column (Transaction Qty × Unit Price)

2️⃣ Analysis (Pivot Tables & Charts)
Compared store performance
Tracked monthly/hourly trends

3️⃣ Dashboard Creation
Built an interactive report for clear visualization
