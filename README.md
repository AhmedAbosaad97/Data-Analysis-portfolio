# SQL & Tableau project

**📊 E-commerce Analysis Project**

I recently worked on an E-commerce dataset using MS SQL Server for data querying and Tableau Public for visualization. The goal was to extract actionable insights that highlight customer behavior, sales performance, and profitability trends.

🔄 My Process

MS SQL Server → cleaned, manipulated, and analyzed the dataset

Tableau Public → visualized results and designed an interactive dashboard to showcase insights

🎯 Objectives

Calculate key metrics: number of customers, total quantities sold, average product price, average shipping cost, gross profit, and net profit

Identify the top-performing product category

Highlight the top 5 cities by net profit

Determine the age group and income bracket with the highest order volume

Compare purchasing behavior between males and females

Analyze sales trends across weekdays

🛠️ Skills & Tools Applied

SQL: SELECT, ORDER BY, GROUP BY, COUNT(), MIN(), MAX(), AVG(), STDEV(), VAR(), IS NULL, UPDATE, CTEs, ALTER TABLE, HAVING

Data Analysis: Exploratory Data Analysis (EDA)

Visualization in Tableau: bar charts, dashboards, containers

📌 Key Insights

Number of customers: 4,734

Quantities sold: 35,367

Average product price: $32.66

Average shipping cost: $15.03

Gross profit: $1,063,605.28

Net profit: $833,659

Business Highlights:

Top-performing category: Home ($198,956 profit)

Top 5 cities by net profit: New York, Los Angeles, Charlotte, Chicago, Houston

Adults place the most orders

Customers in the high-income bracket dominate purchases

Females order more than males

Sales remain steady on weekdays, with a peak on Sundays
